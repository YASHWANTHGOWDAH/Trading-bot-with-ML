# TradeMind AI — MongoDB Database Collections Architecture

This document specifies the MongoDB database schema and collection architecture for **TradeMind AI** (`trademind_ai` database).

TradeMind AI exclusively uses MongoDB (NoSQL) with async Motor driver. No relational/PostgreSQL database is used.

---

## 1. Summary of Collections

| Collection | Purpose | Key Indexes |
| :--- | :--- | :--- |
| `users` | User credentials, profiles, security hashes | `email` (Unique) |
| `market_data` | Historical OHLCV candle records and indicators | `(symbol, timeframe)` |
| `predictions` | Historical ML model inference logs and audit trails | `(symbol, timestamp)` |
| `signals` | Current active BUY/SELL/HOLD signals and confidence | `symbol` (Unique) |
| `trades` | Chronological paper trading execution ledger | `(user_email, timestamp)` |
| `holdings` | Open virtual stock positions per trader | `(user_email, symbol)` |
| `portfolios` | High-level portfolio equity, cash, and P/L | `user_email` (Unique) |
| `watchlists` | User-curated watchlist of priority equities | `(user_email, symbol)` |
| `backtests` | Backtest simulation runs, equity curves, metrics | `(user_email, created_at)` |
| `alerts` | Smart condition triggers (price, signal, confidence) | `(user_email, is_active)` |

---

## 2. Detailed Schemas & Sample Documents

### 1. `users`
Stores user profile information with Argon2 password hashing. Plaintext passwords are never stored.

```json
{
  "_id": ObjectId("65fa0101a1b2c3d4e5f60001"),
  "name": "Yashwanth Gowda",
  "email": "yashwanth@example.com",
  "password_hash": "$argon2id$v=19$m=65536,t=3,p=4$...",
  "created_at": ISODate("2026-10-03T06:30:00Z")
}
```

### 4. `signals`
Stores the latest active signal per ticker for fast O(1) query lookups on the Dashboard and Watchlists.

```json
{
  "_id": ObjectId("65fa0101a1b2c3d4e5f60004"),
  "symbol": "AAPL",
  "signal": "BUY",
  "confidence": 82.0,
  "up_probability": 82.0,
  "down_probability": 18.0,

```

### 10. `alerts`
User-defined condition triggers evaluated continuously against incoming market ticks and AI signals.

```json
{

  "user_email": "yashwanth@example.com",
  "symbol": "AAPL",
  "condition_type": "PRICE_ABOVE",
  "threshold_value": 230.0,
  "is_active": true,
  "is_triggered": false,
  "triggered_at": null,
  "trigger_message": null,
  "created_at": ISODate("2026-10-03T06:35:00Z")
}
```
